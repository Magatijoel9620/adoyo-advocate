## 🏛️ About the Website

A modern digital presence for **Adoyo J & Company Advocates**, a legal practice based in Malindi, Kenya.

The website provides an accessible starting point for individuals and businesses looking to explore legal services, learn about the firm and make direct enquiries.

Designed around clarity, accessibility and trust, it combines a professional legal identity with a contemporary digital experience.

## 🧭 A Better Starting Point for Enquiries

The website helps visitors identify a relevant service category and choose how to contact the firm.

- Enquiries can be initiated through WhatsApp.
- Email links open the visitor's preferred email application.
- Visitors review and send their own WhatsApp messages.

The website does not provide automated legal advice or determine the merits of a legal matter. Enquiries should be directed to the firm for appropriate assistance.

## 🚀 Run Locally

For developers maintaining or contributing to the website:

**Requirements**
- Node.js 22 or later
- npm

**Getting started**

```bash
# Clone the repository
git clone YOUR_REPOSITORY_URL

# Enter the project directory
cd YOUR_PROJECT_DIRECTORY

# Configure environment variables
cp .env.example .env.local

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌍 Production Deployment

The production website uses:

**Canonical domain:** [https://adoyolaw.com](https://adoyolaw.com)

Configure the following environment variable in the hosting provider:

```env
NEXT_PUBLIC_SITE_URL=https://adoyolaw.com
```

### Pre-deployment checklist

- [ ] Confirm production domain, DNS and HTTPS.
- [ ] Verify public phone, WhatsApp and email details.
- [ ] Confirm office address and Google Maps location.
- [ ] Review all public-facing legal information with the firm.
- [ ] Test contact links and enquiry flows.
- [ ] Check desktop, tablet and mobile layouts.
- [ ] Verify metadata, sitemap and social sharing previews.
- [ ] Submit the sitemap through Google Search Console.

### Production checks

```bash
npm ci
npm run lint
npm run build
npm start
```
